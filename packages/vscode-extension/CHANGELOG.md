# Changelog

## 1.0.0

Initial release on VS Code Marketplace and Open VSX.

- Sidebar memory panel with entry counts
- Code lenses on exported symbols
- Status bar with scan timestamp
- Scan Now command (tries memo-log on PATH, falls back to npx)
- scanOnSave support (opt-in)
- Reads custom output paths from .memolog.json
- Untrusted workspace protection
- Read-only webview for full memory file
